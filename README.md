Algoritmos de Sincronización y Liveness (C)
Este repositorio incluye las implementaciones en C del Algoritmo del Panadero de Lamport (exclusión mutua y liveness) y del Algoritmo de Berkeley (sincronización de relojes).
Archivospanadero.c: Implementación de la exclusión mutua para N hilos.
berkeley.c: Simulación de sincronización de relojes entre un maestro y múltiples clientes.
